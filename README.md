# Cairn · 巨石堆

> 本地优先的个人知识 / 资产 / 项目工作台。

一块块往上堆。

## 定位

- **本地优先**：文件是本体，应用只是消费者。数据以普通文件落盘，SQLite 只是可重建的索引。
- **三件套**：笔记、存储、项目管理。
- **桌面端**：Python + PySide6（Qt Widgets）。

## 技术血统

Python 为主体；Rust（PyO3 + maturin）为预留的原生扩展语言，仅在性能热点被证实后启用。不写 C++。

## 北极星

可选择性联邦进一个 P2P 博客网络（服务器可选、公私自决、可发现可私网）。网络是增强层，不是本体。
